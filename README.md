# 🏧 Proyecto: Cajero Automático

## 📋 Descripción

Este proyecto consiste en desarrollar una interfaz web que simula el funcionamiento básico de un **cajero automático**.

El objetivo principal es practicar conceptos fundamentales de **JavaScript**, especialmente:

- Variables.
- Funciones.
- Parámetros.
- Valores de retorno.
- Condicionales.
- Ciclo `while`.
- Manipulación del DOM.
- Creación dinámica de elementos HTML.
- Manejo de eventos.

La interfaz gráfica será desarrollada utilizando **HTML y CSS**, mientras que la lógica del cajero será implementada posteriormente mediante JavaScript.

> **Importante:** El proyecto está diseñado como ejercicio académico. No representa un sistema bancario real y no debe utilizarse para manejar información financiera real.

---

# 🎯 Objetivos

## Objetivo general

Desarrollar una aplicación web que simule las operaciones básicas de un cajero automático, aplicando funciones de JavaScript y manipulación dinámica de la interfaz.

## Objetivos específicos

- Comprender la estructura de una aplicación web interactiva.
- Practicar la creación y utilización de funciones.
- Utilizar parámetros para enviar información a las funciones.
- Utilizar valores de retorno cuando sea necesario.
- Implementar estructuras condicionales.
- Utilizar un ciclo `while` para controlar la interacción con el usuario.
- Manipular elementos HTML desde JavaScript.
- Separar la estructura visual de la lógica de programación.
- Organizar el proyecto de manera modular y comprensible.

---

# 🖥️ Interfaz

La interfaz representa un cajero automático moderno.

Está dividida principalmente en dos áreas:

### Panel lateral

Contiene:

- Nombre del sistema.
- Representación visual del cajero.
- Información del usuario.
- Saldo disponible.
- Botón para cerrar sesión.

### Panel principal

Contiene:

- Mensaje de bienvenida.
- Fecha y hora.
- Opciones disponibles.
- Mensajes de seguridad.

Las operaciones principales son:

1. Consultar saldo.
2. Retirar dinero.
3. Depositar dinero.
4. Consultar últimos movimientos.
5. Cerrar sesión.
